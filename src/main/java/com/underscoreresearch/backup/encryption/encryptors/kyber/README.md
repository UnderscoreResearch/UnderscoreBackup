# Kyber Encryption Package

This package contains the implementation of the Kyber Post-Quantum Cryptography (PQC) algorithm for the Underscore Backup system.

## Files

- **KyberKeyMethod.java**: Implementation of the Kyber key exchange method.

Kyber is a lattice-based key encapsulation mechanism that is believed to be secure against attacks from quantum computers. This implementation provides future-proof security for backup data, ensuring that encrypted data remains secure even in the event of significant advances in quantum computing.
