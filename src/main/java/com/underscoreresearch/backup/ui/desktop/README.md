# CLI UI Package

This package contains classes for managing user interface interactions in desktop environments.

## Files

- **AwtFileUIManager.java**: AWT-based file UI manager implementation.
- **AwtUIManager.java**: AWT-based UI manager implementation.
- **FileUIManager.java**: Interface for file UI operations.
- **OsxUIManager.java**: macOS-specific UI manager implementation.
- **UIHandler.java**: Handles UI events and interactions.
- **UIManager.java**: Interface for UI management.

These classes provide platform-specific UI integration, allowing the backup system to interact with the desktop environment for tasks like file selection, notifications, and system tray integration.
