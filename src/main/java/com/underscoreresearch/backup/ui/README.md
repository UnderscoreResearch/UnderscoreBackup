# CLI Package

This package contains the command-line interface components of the Underscore Backup application, including the main entry point and command handling system.

## Core Files

- **ConfigurationValidator.java**: Validates configuration settings.
- **Main.java**: Main entry point for the application.
- **PasswordReader.java**: Utility for reading passwords securely.

## Subpackages

- **commands**: Contains implementations of specific commands.
- **helpers**: Helper classes for command implementations.
- **desktop**: User interface components for desktop integration.
- **web**: Web server components for the web-based UI.

The CLI package provides both command-line functionality and integration with the web-based user interface, allowing users to interact with the backup system through multiple interfaces.
