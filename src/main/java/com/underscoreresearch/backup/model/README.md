# Backup Model

This package contains the core data models used throughout the Underscore Backup application. These models represent the fundamental entities and concepts in the backup system.

Key components include:

- **BackupActivatedShare**: Represents an activated share for backup data sharing between users
- **BackupActiveFile**: Represents a file that is currently being processed for backup
- **BackupActivePath**: Represents a path that is currently active in the backup process
- **BackupBlock**: Represents a block of data in the backup system
- **BackupConfiguration**: Contains configuration settings for the backup system
- **BackupDestination**: Represents a destination where backup data is stored
- **BackupFile**: Represents a file in the backup repository
- **BackupFilePart**: Represents a part of a file in the backup system
- **BackupLocation**: Represents a location being backed up

These model classes provide the data structures that form the foundation of the backup system, enabling the tracking, processing, and management of backup data throughout the application.
