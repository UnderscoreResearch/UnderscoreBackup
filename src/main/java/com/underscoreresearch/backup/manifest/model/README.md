# Manifest Model

This package contains the data models used by the manifest system in Underscore Backup. These models represent the structure and metadata of backed-up files and directories.

Key components include:

- **BackupDirectory**: Represents a directory structure in the backup repository
- **PushActivePath**: Model for tracking active paths during push operations

These model classes provide the data structures necessary for the manifest system to track and manage the state of backed-up files and directories, enabling efficient storage and retrieval of backup metadata.
