# API Models

This package contains the data models used for communication with the Underscore Backup service API. These models represent the request and response structures for various API endpoints.

Key components include:

- **Request models**: Data structures for API requests
- **Response models**: Data structures for API responses
- **DTO (Data Transfer Objects)**: Objects that transfer data between the client and service

These model classes provide the structured data format for communication with the Underscore Backup service, ensuring proper serialization and deserialization of data during API interactions.
