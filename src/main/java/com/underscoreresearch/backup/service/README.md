# Backup Service

This package contains components for integrating with the optional Underscore Backup service. The service provides features such as configuration coordination, encryption key recovery, and backup data sharing.

Key aspects include:

- **Service API integration**: Communication with the Underscore Backup online service
- **Authentication**: Handling user authentication and authorization with the service
- **Configuration synchronization**: Syncing backup configuration with the service
- **Share management**: Managing the sharing of backup data between users

The service integration is optional, and Underscore Backup can function fully without connecting to the online service. When enabled, the service provides additional convenience features while maintaining the security of the backup data through client-side encryption.

Everything under this directory is autogenerated from the public Underscore Backup API OpenAPI definition and should not be edited manually.
